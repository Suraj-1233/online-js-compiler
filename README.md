# ⚡ Online JS Compiler

A free, fast, and powerful browser-based JavaScript playground to run, test, and debug code snippets instantly. No installation required!

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://suraj-1233.github.io/online-js-compiler/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 🚀 Features

- ✅ **Real-time JavaScript Execution** - Run code instantly with Web Workers
- ✅ **Console Output Display** - See logs, warnings, and errors in real-time
- ✅ **Syntax Highlighting** - Powered by CodeMirror with Dracula theme
- ✅ **Dark/Light Theme Toggle** - Choose your preferred coding environment
- ✅ **Code Sharing** - Share code via URL with automatic encoding
- ✅ **Download & Upload** - Save and load `.js` files
- ✅ **Infinite Loop Protection** - Safe execution environment
- ✅ **Auto-save** - Your code is automatically saved to LocalStorage
- ✅ **Drag-to-Scroll** - Smooth scrolling experience on both editor and console
- ✅ **Mobile Responsive** - Works perfectly on all devices

## 🎯 Use Cases

- **Learning JavaScript** - Perfect for beginners to practice and experiment
- **Testing Code Snippets** - Quickly test JavaScript code without setup
- **Debugging** - Identify and fix errors with real-time console output
- **Sharing Solutions** - Share code with others via URL
- **Teaching** - Great tool for educators and students

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with custom properties
- **JavaScript (ES6+)** - Core functionality
- **CodeMirror** - Code editor with syntax highlighting
- **Web Workers** - Safe code execution in isolated environment
- **LocalStorage API** - Persistent code storage

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/surajkannujiya/online-js.git
cd online-js
```

2. Serve locally:
```bash
npx http-server -p 8080
```

3. Open in browser:
```
http://localhost:8080
```

## 🌐 Deployment

This project is deployed on **GitHub Pages**. To deploy your own version:

1. Fork this repository
2. Go to Settings → Pages
3. Select `main` branch as source
4. Your site will be live at `https://yourusername.github.io/online-js/`
